# 学习网页源码（2026-10-26）

本目录备份今天重做的错题/薄弱点仪表盘及每日语法背诵区。公开源码不改变线上网页的访问权限。

## 本地运行

在本目录运行 `python -m http.server 8000 --directory dist`，访问本机 8000 端口。无需安装依赖。

## 验证

运行 `node --test tests/model.test.cjs tests/grammar.test.cjs`。

## 数据和范围

- 68条可核学习记录；并非全部历史。
- 默认33题为首次记录的外部照片作答，18题正确，外部提示条件未知。
- 严格独立、复测、提示后作答分开；未测模块不记0分；累计错题排行不受仪表的作答口径隐藏。
- 82张语法卡：67复习重点＋15基础衔接。部分有历年资料中的出现记录，不是官方必考/频次榜。
- 每日8卡：最多5张弱项优先，其余轮换。背诵打卡只保存在当前浏览器，不计准确率。
- 网页是发布快照，聊天记录不会自动写入网页；支持本地JSON导入/导出，跨设备需重新发布或自行转移导出文件。
- 旧版私人历史快照、私有托管标识、原题PDF和账号凭据不在本目录。源码中的个人来源标识和私人云盘链接已去除。
- 统计/排序/导入测试已通过；登录后线上画面此前未能直接核验。
